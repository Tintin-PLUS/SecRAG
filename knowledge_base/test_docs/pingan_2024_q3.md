# 中国平安2024年三季报分析

## 公司概况

中国平安（601318.SH/2318.HK）是中国领先的综合金融服务集团，业务涵盖寿险、产险、银行、资产管理、医疗健康等板块。2024年三季度公司实现营业收入9812.6亿元，同比增长4.7%；归母净利润1191.2亿元，同比增长9.5%。公司总资产约11.8万亿元，稳居国内混合所有制金融集团前列。

## 财务分析

寿险新业务价值（NBV）方面，2024年三季度NBV为356.4亿元，同比增长11.0%。NBV利润率为25.3%，同比提升2.1个百分点，主要受益于产品结构优化和费用率下降。新单保费收入为1409.8亿元，同比增长3.2%，其中期交保费占比71.5%。

产险方面，三季度产险原保险保费收入2586.3亿元，同比增长5.5%。综合成本率为97.8%，同比优化1.2个百分点。其中车险综合成本率为95.3%，非车险综合成本率为101.5%。赔付率为62.1%，费用率为35.7%。

归母净资产收益率为14.2%，同比下降0.3个百分点。集团内含价值为9582.3亿元，同比增长6.8%。

## 寿险业务

渠道方面，代理人渠道新单保费为820.5亿元，同比增长2.1%。代理人数量从2023年末的36.4万降至34.2万，但人均产能提升15.3%，月人均新单保费达到1.2万元。银保渠道新单保费为385.6亿元，同比增长8.5%。

产品方面，公司持续推进"保险+服务"模式，健康管理服务覆盖用户超过2.3亿。长期重疾险占比从55%调整至48%，增额终身寿险占比提升至22%，储蓄型产品占比30%。

## 资管与科技

资产管理方面，集团投资资产规模达5.2万亿元，其中股票投资占比8.5%，债券投资占比62.3%。三季度总投资收益率为4.5%，同比提升0.3个百分点。

科技业务方面，平安好医生注册用户达4.8亿，月活用户7200万。金融壹账通已服务598家银行和108家保险公司。平安科技在AI专利申请数超过5300项，位居全球金融科技专利前列。

## 业务展望

寿险改革进入深水区，公司计划2025年进一步压缩低产能代理人队伍，目标月人均新单保费突破1.5万元。医疗健康板块将加大投入，目标覆盖3亿用户。分红方面，公司2024年中期股息为每股0.93元，全年股息率预计维持在5%左右。

## 风险提示

利率下行可能压缩寿险投资收益。权益市场波动影响投资端收益。偿付能力监管趋严可能要求补充资本。保险行业竞争加剧，中小险企价格战可能传导至大型险企。
