# 宁德时代2024年三季报分析

## 公司概况

宁德时代（300750.SZ）是全球领先的新能源电池制造商，主要产品包括动力电池、储能电池和电池回收材料。2024年三季度公司实现营业收入986.3亿元，同比下降7.0%；归母净利润104.3亿元，同比下降15.1%。

## 财务分析

毛利率方面，2024年三季度公司综合毛利率为23.5%，环比下降1.2个百分点。其中动力电池业务毛利率为21.8%，储能电池业务毛利率为28.3%。净利率为10.6%，同比下降0.9个百分点。

研发费用方面，三季度研发投入为45.2亿元，占营收比重为4.6%，同比下降8.3%。

## 市场份额

根据SNE Research数据，2024年1-9月宁德时代全球动力电池装机量市场份额为36.8%，稳居全球第一。其中中国市场份额为43.1%，海外市场份额为28.5%。

## 业务展望

动力电池方面，公司持续扩大海外产能布局，匈牙利工厂已开始量产，印度尼西亚工厂预计2025年投产。储能电池方面，公司推出了全新一代314Ah电芯产品，循环寿命超过12000次。

## 风险提示

1. 新能源车销量不及预期
2. 原材料价格大幅波动
3. 海外贸易政策变化
4. 行业竞争加剧导致毛利率持续承压

## 投资建议

维持买入评级。预计2024-2026年EPS分别为10.2/12.5/15.8元，对应PE分别为20/16/13倍。考虑到公司在动力电池和储能领域的领先地位，以及海外扩张带来的增长空间，维持买入评级。
