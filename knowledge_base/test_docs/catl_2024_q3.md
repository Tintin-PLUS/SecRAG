# 宁德时代2024年三季报分析

## 公司概况

宁德时代（300750.SZ）是全球领先的新能源电池制造商，主要产品包括动力电池、储能电池和电池回收材料。2024年三季度公司实现营业收入986.3亿元，同比下降7.0%；归母净利润104.3亿元，同比下降15.1%。总市值约1.15万亿元，稳居全球动力电池行业市值第一。

## 财务分析

毛利率方面，2024年三季度公司综合毛利率为23.5%，环比下降1.2个百分点。其中动力电池业务毛利率为21.8%，储能电池业务毛利率为28.3%。净利率为10.6%，同比下降0.9个百分点。

研发费用方面，三季度研发投入为45.2亿元，占营收比重为4.6%，同比下降8.3%。公司累计研发投入超过500亿元，拥有研发人员超过2万人，全球专利申请超过3万项。

产能方面，截至2024年三季度，公司全球规划产能超过680GWh，已投产产能超过400GWh。产能利用率约78.5%，同比下降5.2个百分点，主要受行业增速放缓影响。

## 市场份额

根据SNE Research数据，2024年1-9月宁德时代全球动力电池装机量市场份额为36.8%，稳居全球第一。其中中国市场份额为43.1%，海外市场份额为28.5%。

储能电池方面，全球储能电池出货量份额为38.5%，连续三年保持全球第一。2024年三季度储能电池出货量42.5GWh，同比增长25.6%。

主要竞争对手比亚迪市场份额为16.3%，LG新能源为14.5%，松下为8.2%。宁德时代领先第二名比亚迪超过20个百分点。

## 产品技术

产品方面，公司推出了新一代麒麟电池（CTP 3.0），系统能量密度达到255Wh/kg，支持4C快充，10分钟充电80%。麒麟电池已在极氪、问界、理想等多款车型搭载。

钠离子电池方面，二代钠离子电池能量密度提升至160Wh/kg，循环寿命超过12000次。已在奇瑞、五菱等A0/A00级车型量产应用。计划2025年在储能领域大规模推广。

凝聚态电池方面，公司凝聚态电池能量密度达到500Wh/kg，已在航空领域开展测试。计划2026年在高端电动汽车领域小批量应用。

M3P电池方面，M3P磷酸盐电池已搭载于特斯拉Model 3焕新版，能量密度达到210Wh/kg，较磷酸铁锂提升15%，成本降低8%。

## 业务展望

动力电池方面，公司持续扩大海外产能布局，匈牙利工厂已开始量产，印度尼西亚工厂预计2025年投产，规划年产能100GWh。公司目标2025年海外装机量占比提升至35%。

储能电池方面，公司推出了全新一代314Ah电芯产品，循环寿命超过12000次，能量密度达到350Wh/L。已在大型储能项目批量交付，中标多个GWh级订单。

电池回收方面，公司子公司邦普循环回收产能达到15万吨/年，回收镍钴锰金属回收率超过99.5%。2024年回收业务收入预计超过80亿元。

换电方面，公司推出了"巧克力换电"方案，90秒完成换电，已在10个城市部署超过200座换电站。与多家车企达成换电合作协议，目标2025年换电站超过1000座。

## 风险提示

动力电池行业产能过剩，价格持续下行。2024年三季度电芯均价0.42元/Wh，同比下降25.6%。原材料价格波动，碳酸锂价格从60万元/吨下跌至7.5万元/吨。海外贸易壁垒，美国IRA法案对电池供应链本土化要求提高。技术路线竞争，固态电池、钠离子电池等新技术可能颠覆现有格局。
