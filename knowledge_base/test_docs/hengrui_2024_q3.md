# 恒瑞医药2024年三季报分析

## 公司概况

恒瑞医药（600276.SH）是中国领先的创新药企业，业务涵盖抗肿瘤、麻醉、造影剂、自身免疫疾病等领域。2024年三季度实现营业收入203.5亿元，同比增长15.3%；归母净利润43.2亿元，同比增长18.5%。总市值约3200亿元，是A股市值最大的医药企业。

## 财务分析

毛利率方面，2024年三季度综合毛利率为84.6%，同比提升1.8个百分点。其中创新药毛利率88.2%，仿制药毛利率72.5%。净利率为21.2%，同比提升0.6个百分点。

研发投入方面，三季度研发费用为48.5亿元，占营收23.8%，同比增长14.5%。其中研发费用化38.8亿元，资本化9.7亿元，研发费用化率80.0%。公司累计投入研发超过400亿元，在A股医药企业中研发投入持续排名第一。

销售费用为56.3亿元，占营收27.7%，同比下降2.3个百分点，主要受集采影响和学术推广模式转型。管理费用为12.5亿元，占营收6.1%。财务费用-1.2亿元，主要为利息收入。

## 创新药管线

上市产品方面，公司已有15个创新药获批上市。卡瑞利珠单抗（PD-1）覆盖肺癌、肝癌、食管癌等8个适应症，2024年预计销售额超过45亿元。阿帕替尼（VEGFR2）联合用药方案扩展至5个适应症。氟唑帕利（PARP抑制剂）和海曲泊帕（TPO-RA）快速放量中。

在研管线方面，III期临床阶段品种12个，II期临床品种18个，I期临床品种25个。重点管线包括：SHR-1701（PD-L1/TGF-β双抗）III期数据读出，SHR-A1811（HER2 ADC）申报上市，SHR-1316（BTK抑制剂）II期疗效优异。

海外授权方面，2024年公司已完成4项License-out交易，总交易金额超过25亿美元。其中卡瑞利珠单抗联合用药方案授权给默克，首付款3.5亿欧元。公司累计海外授权收入超过40亿美元。

## 仿制药与集采

集采影响方面，公司已有35个品种进入国家集采，其中中标品种28个。集采品种合计影响收入约85亿元，同比下降12.5%。通过一致性评价的品种超过65个。

仿制药收入方面，三季度仿制药收入78.5亿元，同比下降5.8%。其中抗肿瘤仿制药收入28.3亿元，麻醉类仿制药22.5亿元，造影剂15.8亿元，其他12.0亿元。

## 业务展望

创新药方面，公司目标2025年创新药收入占比超过55%，2030年创新药收入占比超过80%。管线方面，计划2025年申报3个新药上市（HER2 ADC、JAK抑制剂、NRAS抑制剂）。

国际化方面，公司在美国建立3个研发中心，欧洲建立2个临床中心。目标2025年海外收入占比提升至15%。卡瑞利珠单抗美国上市申请计划2026年提交。

分红方面，2024年中期股息为每10股派2元。公司将持续加大回购力度，2024年已回购金额超过10亿元。

## 风险提示

医保谈判降价压力，创新药纳入医保后通常降价50-60%。临床试验失败风险，III期临床成功率约60%。海外授权交易存不确定性，里程碑付款可能不及预期。仿制药集采持续降价，利润空间收窄。管线竞争激烈，PD-1、HER2 ADC等领域竞争白热化。
