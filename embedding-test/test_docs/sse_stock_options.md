# 沪市股票期权交易基础

> 数据集说明：根据上交所股票期权投资者服务材料整理。抓取日期：2026-09-07。
> 来源：https://one.sse.com.cn/onething/qqtz/

沪市股票期权交易时段包括9:15至9:25、9:30至11:30和13:00至15:00。9:15至9:25为开盘集合竞价，14:57至15:00为收盘集合竞价，其余交易时段按规则进行连续竞价。

个人投资者的期权交易权限分为一级、二级和三级。一级权限主要覆盖备兑开仓、持有标的时买入认沽以及平仓或行权；二级在一级基础上增加买入开仓；三级还可以进行保证金卖出开仓。

申请相应级别权限需要符合适当性要求，包括知识测试和相应的期权模拟交易经历。
