# 2024年转融券与融券保证金调整

> 数据集说明：根据证监会2024年7月公开信息整理。抓取日期：2026-09-07。
> 来源：https://www.csrc.gov.cn/csrc/c100028/c7493852/content.shtml

证监会批准中证金融公司自2024年7月11日起暂停转融券业务。存量转融券合约可以按安排展期，但当时明确不得晚于2024年9月30日了结。

同时，交易所将普通投资者融券保证金比例由不低于80%上调至不低于100%；私募证券投资基金参与融券的保证金比例由不低于100%上调至不低于120%。保证金比例调整自2024年7月22日起实施。

这些安排属于融券业务的逆周期调节措施，目标包括维护市场稳定、加强客户交易行为管理并防范不当套利。
