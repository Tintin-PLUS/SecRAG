# 北交所竞价交易核心规则

> 数据集说明：根据北京证券交易所交易规则整理。抓取日期：2026-09-07。
> 来源：https://www.bse.cn/jygl_list/200028217.html

北交所股票竞价交易的单笔申报数量不低于100股，卖出时余额不足100股的部分应一次性申报卖出，单笔申报最大数量不超过100万股，申报价格最小变动单位通常为0.01元。

北交所股票日常竞价交易的价格涨跌幅限制比例为30%。公开发行股票上市首日和退市整理期首日等情形不设涨跌幅限制。

对无价格涨跌幅限制的股票，当盘中价格较当日开盘价首次上涨或下跌达到30%或60%时，交易所实施盘中临时停牌，单次停牌时间为10分钟。
