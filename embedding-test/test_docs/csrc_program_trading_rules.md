# 证券市场程序化交易管理要点

> 数据集说明：根据证监会公开材料整理的中文测试语料，不是法规原文。抓取日期：2026-09-07。
> 来源：https://www.csrc.gov.cn/csrc/c100028/c7480577/content.shtml

证监会发布的《证券市场程序化交易管理规定（试行）》自2024年10月8日起实施。程序化交易是通过计算机程序自动生成或者下达交易指令并在证券交易所进行证券交易的行为。

规定强调“先报告、后交易”。投资者应按要求报告账户、资金、交易和软件等信息，完成报告义务后再开展程序化交易。证券交易所对相关交易实施实时监控，证券公司承担客户管理职责，机构投资者需要落实合规与风险控制要求。

监管范围还覆盖交易系统、交易单元、主机托管和信息系统接入。对高频交易，规则从报告信息、收费和交易监控等方面提出差异化安排，并要求不得影响交易所系统安全或扰乱正常交易秩序。
