# 美的集团2024年三季报分析

## 公司概况

美的集团（000333.SZ）是全球领先的家电企业，业务涵盖暖通空调、消费电器、机器人与自动化、智能供应链、楼宇科技五大板块。2024年三季度实现营业收入3189.5亿元，同比增长4.7%；归母净利润316.5亿元，同比增长12.1%。总市值约4800亿元，是A股市值最大的家电企业。

## 财务分析

毛利率方面，2024年三季度综合毛利率为25.8%，同比提升1.5个百分点。其中暖通空调毛利率28.2%，消费电器毛利率30.5%，机器人及自动化毛利率21.8%。净利率为9.9%，同比提升0.7个百分点，盈利能力持续改善。

分业务收入方面，暖通空调业务收入1385.6亿元，占比43.4%；消费电器收入986.3亿元，占比30.9%；机器人与自动化收入285.4亿元，占比8.9%；智能供应链收入152.8亿元，占比4.8%；楼宇科技收入379.4亿元，占比11.9%。

海外收入占比42.5%，达1355.7亿元，同比增长7.3%。内销收入1833.8亿元，同比增长3.1%。电商渠道收入占比35.8%，线下渠道占比49.2%，工程渠道占比15.0%。

## 暖通空调业务

家用空调方面，三季度内销出货量3850万套，同比增长5.2%。市场份额32.5%，同比提升0.8个百分点，稳居行业第一。中央空调方面，多联机市场份额28.5%，水机市场份额18.3%。

出口方面，三季度空调出口量1250万套，同比增长12.5%。主要增长来自东南亚（+18%）、中东（+22%）、拉美（+15%）。OBM（自有品牌）出口占比42.3%，同比提升5个百分点。

库卡机器人方面，三季度收入98.5亿元，同比增长8.2%。其中汽车行业收入占比35%，电子行业25%，物流15%，医疗等其他25%。库卡在中国区收入增长15.6%，中国区占比提升至38.5%。

## 智能化与数字化

美的工业互联网平台已服务超过500家企业，连接设备超过200万台。美云智建SaaS服务覆盖1200家中小企业，年收入增长35%。美的AI质检系统已在45家工厂部署，检测准确率达到99.8%。

智能家居方面，美居App注册用户1.5亿，月活用户6200万。全屋智能解决方案已在2000家门店推广，客单价超过1.5万元。搭载美的自研美仁芯片的智能家电产品出货量超过800万台。

## 业务展望

公司目标2025年营收突破3500亿元，净利润增速保持两位数。海外市场将加大东南亚和印度投入，目标海外收入占比提升至50%。机器人板块将聚焦汽车制造和物流自动化，目标库卡中国区收入增速超过20%。

分红方面，2024年中期股息为每10股派15元，现金分红率约40%。公司计划2025-2027年每年分红率不低于40%，并继续实施股票回购计划。

## 风险提示

房地产下行影响家电内需。原材料价格波动，铜、铝、钢材占成本40%以上。海外贸易摩擦，美国对华家电加征关税可能影响出口。库卡整合不及预期，欧洲制造业PMI持续低于荣枯线。
