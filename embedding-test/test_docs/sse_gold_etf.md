# 黄金ETF交易与申赎要点

> 数据集说明：根据上交所黄金ETF业务指南整理。抓取日期：2026-09-07。
> 来源：https://www.sse.com.cn/assortment/fund/etf/rules/c/c_20150911_3985190.shtml

上交所黄金ETF的申报价格最小变动单位为0.001元。买入申报数量通常为100份或其整数倍，持有余额不足100份时可以卖出。

指南所述黄金ETF交易涨跌幅限制为10%。交易时段与上交所相关基金交易安排衔接，包括上午集合竞价、上午和下午连续竞价等时段。

在申购赎回环节，基金管理人于开市前公布申购赎回清单以及总量限额。投资者通过代办券商提交申赎申报，券商检查对价是否足额，交易系统再按规则处理确认。
