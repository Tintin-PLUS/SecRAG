# 沪市竞价交易时段与撤单安排

> 数据集说明：根据《上海证券交易所交易规则（2026年修订）》整理。抓取日期：2026-09-07。
> 来源：https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml

沪市竞价交易接受申报的主要时段为9:15至9:25、9:30至11:30和13:00至15:00。其中9:15至9:25为开盘集合竞价，14:57至15:00为收盘集合竞价。

撤单并非在所有申报时段都可进行。开盘集合竞价的9:20至9:25以及收盘集合竞价的14:57至15:00，交易主机不接受撤单申报；其他接受交易申报的时段，未成交申报可以按规则撤销。

连续竞价行情通常包括最新价、最高价、最低价、累计成交数量和金额，以及买卖五档价格与数量。
