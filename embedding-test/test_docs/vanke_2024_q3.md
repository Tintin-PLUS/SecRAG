# 万科A 2024年三季报分析

## 公司概况

万科企业（000002.SZ）是中国领先的房地产开发企业，业务涵盖住宅开发、物业管理、物流仓储、商业运营、长租公寓等领域。2024年三季度实现营业收入2876.5亿元，同比下降15.2%；归母净利润-85.6亿元，同比转亏。总市值约1850亿元。

## 财务分析

毛利率方面，2024年三季度综合毛利率为8.5%，同比下降6.8个百分点。其中开发业务毛利率5.2%，物业服务毛利率18.5%，物流仓储毛利率25.3%。净利率为-3.0%，行业整体进入深度调整期。

营收下降主要受结算规模缩减影响。三季度结算面积1850万平方米，同比下降25.3%。结算均价14250元/平米，同比下降5.5%。

合同负债为5685.3亿元，较年初下降8.5%，覆盖未来一年结算约1.2倍。已售未结资源金额6320亿元，其中一二线城市占比68.5%。

## 销售情况

合同销售方面，三季度合同销售金额2156.8亿元，同比下降18.5%。合同销售面积1625万平方米，同比下降22.3%。销售均价13285元/平米，同比微增3.8%，主要因一二线城市销售占比提升。

分区域看，南方区域销售658亿元，占比30.5%；上海区域582亿元，占比27.0%；北方区域456亿元，占比21.1%；西部区域285亿元，占比13.2%；华中区域176亿元，占比8.2%。

拿地方面，三季度新增土地储备385万平方米，总地价425亿元。新增项目主要位于一二线城市，一二线占比85.5%。平均楼面价6823元/平米，占当期售价51.4%。

## 多元业务

物业管理方面，万物云管理面积9.8亿平方米，覆盖510个城市。万物梁行（商业物业）在管面积1.2亿平方米。三季度物业收入256.8亿元，同比增长8.5%，毛利率18.5%。

物流仓储方面，万纬物流在管面积1200万平方米，覆盖55个城市。冷链收入占比35.2%，三季度收入38.5亿元，同比增长12.3%。出租率92.5%，冷库出租率88.3%。

长租公寓方面，泊寓在管房源18.5万间，覆盖40个城市。三季度收入28.6亿元，同比增长15.8%，平均出租率89.5%。已实现单月盈利。

商业运营方面，在管商业项目158个，建筑面积1320万平方米。三季度租金收入42.5亿元，同比增长5.2%。印力集团管理面积890万平方米，出租率93.8%。

## 资产负债

总资产1.56万亿元，总负债1.15万亿元，净资产4100亿元。资产负债率73.7%，剔除预收账款后实际负债率56.3%。

现金方面，货币资金856.5亿元，短期借款和一年内到期有息负债832.2亿元，现金短债比1.03。有息负债总额3285.6亿元，其中银行贷款占比58.5%，债券占比28.3%，非标占比13.2%。

融资成本方面，新增融资平均利率4.15%，较存量负债加权平均利率4.38%下降23BP。境外债余额185亿元，占整体有息负债5.6%。

## 业务展望

公司目标2025年实现经营性现金流为正，2026年回归盈利。开发业务将聚焦核心城市核心地段，拿地权益比维持在70%以上。物业板块计划分拆万物云海外业务独立上市。

经营性收入方面，目标2025年经营性收入（物业+物流+商业+长租）突破500亿元，占比提升至15%以上。REITs方面，中金万科REIT已上市，募集规模38.5亿元。计划新增2个REIT项目。

## 风险提示

房地产销售不及预期，三四线城市库存压力大。部分项目亏损结算持续影响利润。债务到期压力，2025年境内债券到期352亿元。经营性业务盈利周期长，短期难以覆盖开发业务亏损。政策变化不确定性，限购限贷政策调整影响需观察。
