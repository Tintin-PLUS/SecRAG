# 上市公司市值管理监管要点

> 数据集说明：根据证监会市值管理指引及公开说明整理。抓取日期：2026-09-07。
> 来源：https://www.csrc.gov.cn/csrc/c101954/c7519046/content.shtml
> 来源：https://www.csrc.gov.cn/csrc/c100028/c7467850/content.shtml

《上市公司监管指引第10号——市值管理》于2024年11月6日公布并施行。市值管理以提高上市公司质量为基础，目标是提升投资者回报能力和水平，而不是短期炒作股价。

上市公司可以依法合规运用并购重组、股权激励、员工持股、现金分红、投资者关系管理、信息披露、股份增持和回购等方式提升投资价值。

监管明确反对“伪市值管理”。借市值管理名义从事选择性或虚假信息披露、内幕交易、市场操纵等行为，触及合规红线。
