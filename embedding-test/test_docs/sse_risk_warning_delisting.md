# 沪市风险警示与退市整理交易

> 数据集说明：根据上交所2026年交易规则和上市规则整理。抓取日期：2026-09-07。

沪市主板风险警示股票和处于退市整理期的主板股票在风险警示板交易。投资者买卖这两类股票应采用限价委托方式。投资者当日通过竞价、大宗和盘后固定价格交易累计买入单只风险警示股票，通常不得超过50万股。

退市整理期的交易期限为15个交易日。股票在退市整理期内全天停牌的，停牌时间不计入15个交易日，但累计停牌通常不得超过5个交易日。退市整理期届满后，股票将按规则被终止上市并摘牌。
