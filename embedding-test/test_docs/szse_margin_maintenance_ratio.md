# 融资融券维持担保比例计算

> 数据集说明：根据深交所投资者教育材料整理。抓取日期：2026-09-07。
> 来源：https://investor.szse.cn/knowledge/t20190828_569684.html

维持担保比例用于衡量信用账户担保资产对融资融券负债的覆盖程度。其基本计算思路是：分子为现金、信用证券账户内证券市值以及其他担保物价值之和；分母为融资买入金额、融券卖出证券按当前市价计算的金额，以及利息和费用之和。

因此，担保物市值下跌、融券标的价格上涨或利息费用增加，都可能压低维持担保比例。券商可以在交易所规则和合同框架内设置风险控制要求，投资者应关注追保、限制交易和强制平仓风险。
