# 创业板涨跌幅与交易公开信息

> 数据集说明：根据深交所投资者教育材料整理。抓取日期：2026-09-07。
> 来源：https://investor.szse.cn/index/update/t20200729_580056.html
> 来源：https://investor.szse.cn/institute/rules/t20200903_581256.html

首次公开发行上市的创业板股票，上市后的前5个交易日不设价格涨跌幅限制；此后，创业板股票竞价交易涨跌幅限制比例为20%。

对于有涨跌幅限制的创业板股票，交易公开信息关注三类典型阈值：当日收盘价涨跌幅达到正负15%、价格振幅达到30%、换手率达到30%。达到规定条件的股票，深交所披露当日买入和卖出金额较大的营业部或交易单元信息。

这些差异化安排提高了定价空间，也意味着投资者需要关注更大的日内波动风险。
