# 程序化交易异常监控指标

> 数据集说明：根据证监会公开答记者问整理的中文测试语料。抓取日期：2026-09-07。
> 来源：https://www.csrc.gov.cn/csrc/c100028/c7493840/content.shtml

证监会在程序化交易监管框架下指导沪深北交易所制定实施细则，并持续加强交易监测。公开材料列举了四类重点监控指标：瞬时申报速率异常、频繁瞬时撤单、频繁拉抬打压、短时间大额成交。

这些指标用于识别可能影响市场秩序的异常程序化交易行为。监管机构会对频繁触发指标的投资者进行提示和督促，推动程序化交易规范运行。监控并不等同于否定量化交易，而是强调交易公平、系统安全和风险防控。
