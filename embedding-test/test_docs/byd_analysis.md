# 比亚迪深度分析报告

## 公司概况

比亚迪股份有限公司（002594.SZ）是中国领先的新能源汽车和动力电池企业。公司业务涵盖新能源汽车、动力电池、半导体和轨道交通等领域。2024年公司新能源汽车销量达到302万辆，同比增长28%。

## 财务表现

2024年比亚迪实现营业收入6023亿元，同比增长29.5%；归母净利润300亿元，同比增长80.4%。汽车业务毛利率为23.2%，同比提升3.5个百分点。公司整体净利率为5.0%，同比提升1.4个百分点。

## 技术优势

DM-i超级混动系统是比亚迪的核心技术之一，亏电油耗仅为3.8L/100km。刀片电池采用磷酸铁锂路线，安全性高、循环寿命长。公司还推出了CTB电池车身一体化技术，将电池与车身地板融为一体。

## 市场地位

2024年比亚迪新能源汽车国内市场份额为33.2%，连续两年蝉联中国新能源汽车销量冠军。海外市场方面，2024年出口新能源汽车24万辆，同比增长347%。

## 风险提示

1. 补贴退坡对销量的影响
2. 电池原材料价格波动
3. 海外市场竞争加剧
4. 智能化技术追赶不足
