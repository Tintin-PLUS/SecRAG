# 科创板交易与投资者适当性

> 数据集说明：根据上交所2026年交易规则整理。抓取日期：2026-09-07。
> 来源：https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml

个人投资者申请开通科创板股票交易权限，通常需要在申请前20个交易日证券账户及资金账户的日均资产不低于50万元，并具有24个月以上证券交易经历；融资融券融入的资产不计入该资产门槛。

科创板股票日常竞价交易的涨跌幅限制比例为20%。首次公开发行上市股票的前5个交易日不设价格涨跌幅限制。科创板可以实行做市商机制，做市商按规则提供双边报价服务。

有涨跌幅限制的科创板股票若日收盘涨跌幅达到正负15%、日振幅达到30%或日换手率达到30%，交易所按规则披露相关交易公开信息。
