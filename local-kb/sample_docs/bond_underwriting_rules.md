# 债券承销业务规则（模拟）

本文件为演示数据，不对应任何真实机构制度。债券项目立项前，承销团队应完成发行人基本情况、偿债能力、募集资金用途和重大风险事项的初步核验。项目负责人、质量控制人员和合规人员应保持职责分离。

尽职调查材料应形成可追溯底稿。对财务数据的异常波动、关联交易、或有负债和受限资产，应取得解释并执行交叉验证。未经核验的材料不得直接写入申报文件。

簿记建档期间应执行投资者适当性检查，报价、配售和利益冲突信息应留痕。发现重大不利变化时，项目组应暂停推进并重新评估信息披露和发行条件。

存续期内应关注发行人定期报告、兑付安排和信用风险事件。涉及重大事项时，应按照内部升级路径报告，并保留沟通记录。
