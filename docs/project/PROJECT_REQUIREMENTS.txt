# 证券 PC 端侧轻量化本地知识库 Demo —— 完整项目构建需求

你现在需要从零设计并实现一个：

“证券 PC 端侧轻量化本地知识库原型 Demo”。

项目目录：

D:\Workspace\local-kb

请完整阅读本需求和另外提供的《Codex 项目构建前环境说明》。

==================================================
一、课题背景
==================================================

证券投研、交易业务需查阅海量金融文档。

云端知识库存在：

数据合规风险
敏感资料上传风险
网络依赖
离线不可用

等问题。

端侧轻量化向量技术逐步成熟，

本地 PC 离线知识库可以实现：

敏感金融数据终端闭环存储

但证券公司 PC 端知识库在：

框架选型
轻量化部署
增量更新
离线业务适配
低配置 PC 适配
Embedding 模型适配

等方面缺少落地参考。

本课题：

以调研研究为核心，

辅以简易实践验证，

探明：

Tauri + Rust

端侧知识库技术路线的落地可行性，

为公司未来 PC 端离线智能金融应用提供技术依据。
